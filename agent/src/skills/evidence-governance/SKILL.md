# 证据治理框架

## 目的

确保 LLM 生成的投资研究具备可验证的证据基础，防止幻觉、确认偏误和过度自信。此 Skill 应作为所有研究类 Swarm Agent 的基础参考。

## 5 级证据分级

每条用于支撑投资论点的证据，必须标注其来源等级：

| 等级 | 来源类型 | 权重 | 示例 |
|------|----------|------|------|
| **P0** | 公司公告/财报/SEC filing | 1.0 | 年报收入拆分、产能公告、8-K 重大合同 |
| **P1** | 券商研报/行业白皮书 | 0.8 | 卖方研报的行业空间测算、产能调研数据 |
| **P2** | 行业专家/投资者关系 | 0.6 | IR 互动平台回复、行业协会数据 |
| **P3** | 财经媒体/新闻 | 0.4 | 主流财经媒体报道（非自媒体） |
| **P4** | 社交媒体/论坛/KOL | 0.2 | Twitter/雪球/股吧帖子 |

### 分级规则

- 同一事实有多个来源时，取**最高等级**来源
- 每条核心论点至少需要 1 个 P0 或 P1 来源支撑
- 仅有 P3/P4 来源的论点，必须标注 `[未经一手数据验证]`
- 数据优于观点：有具体数字的 P1 优于模糊表述的 P0

## 置信度自动降级

最终研究结论的置信度受证据等级约束：

| 证据组合 | 置信度上限 | 说明 |
|----------|-----------|------|
| 有 ≥2 个独立 P0 来源 | **高 (High)** | 可作为高仓位依据 |
| 有 ≥1 个 P0 + ≥1 个 P1 | **高 (High)** | 交叉验证通过 |
| 仅有 P1 来源（无 P0） | **中 (Medium)** | 需等待 P0 确认 |
| 仅有 P2 + P3 | **低 (Low)** | 仅作为研究线索 |
| 仅有 P4 | **极低 (Very Low)** | 不可作为投资依据 |

### 降级触发器

以下情况自动降低一个等级：
- 核心论点的支撑证据 >6 个月未更新
- 不同 P0 来源之间存在矛盾
- 关键数字来自单一分析师估算（非公司披露）
- 产能/订单数据来自"行业消息"而非公司确认

## 禁用词扫描

### 阻断级（必须修改后才能输出）

以下措辞反映过度自信或合规风险，出现时必须重写：

**中文**: 强烈推荐、必涨、保证盈利、目标价XX元、翻倍潜力、无风险、确定性机会、买入即赚

**English**: strong buy, guaranteed, will definitely, target price $X, can't lose, no-brainer, slam dunk, sure thing

### 警告级（标注后可保留）

以下措辞需追加限定条件：

**中文**: 大概率、极大可能、几乎确定 → 追加概率估计和前提条件

**English**: highly likely, almost certain, very probable → add probability estimate and assumptions

### 推荐替代措辞

| 不推荐 | 推荐 |
|--------|------|
| "AI 需求爆发" | "AI 推理 GPU 出货量 2025 Q2 同比增长 X%（NVIDIA 财报）" |
| "卡脖子地位稳固" | "全球合格供应商 3 家，认证周期 24 个月（公司年报 P.XX）" |
| "估值便宜" | "PE-TTM 15x，位于近 5 年 25% 分位（vs 行业中位数 22x）" |

## 反鹦鹉测试

LLM 输出在发送给用户前，必须通过以下 7 项检查。任一不通过则重写该部分。

### 输出层检查

| # | 检查项 | 不合格示例 | 合格示例 |
|---|--------|-----------|----------|
| 1 | **具体性** — 是否指出了具体的约束关系 | "AI 需求强劲" | "NVIDIA H200 对 InP 晶圆的需求量是 A100 的 3.2x" |
| 2 | **可量化** — 关键主张是否附带数字 | "市场份额很高" | "前 3 大供应商市占率 78%（IHS 2025Q1）" |
| 3 | **可溯源** — 是否标注了数据出处 | "据了解产能紧张" | "公司 2025 半年报显示产能利用率 94%（P.32）" |
| 4 | **有时效** — 数据是否标注时间 | "增速很快" | "2025Q1 营收同比 +47%（vs 2024Q1 +23%）" |
| 5 | **有对比** — 是否与基准/历史/同行比较 | "毛利率不错" | "毛利率 42% vs 行业中位数 28%，近 3 年从 31% 提升至 42%" |
| 6 | **有约束** — 结论是否附带前提条件 | "建议买入" | "在 CPO 渗透率 >15% 且公司产能按计划释放的前提下" |
| 7 | **有反面** — 是否包含反面论据 | （仅列利好） | "主要风险：客户 A 占收入 52%，若其切换供应商..." |

### 过程层检查

| # | 检查项 |
|---|--------|
| A | 是否先完成了看空逻辑再写看多结论 |
| B | 是否为每个核心论点标注了证据等级 |
| C | 是否独立验证了数字（非简单重复来源） |
| D | P4 级来源是否仅用于发现线索，未用于支撑结论 |
| E | 是否存在循环论证（用结论证明结论） |
| F | 不同时间段的数据是否正确标注（非混用） |

## 前瞻性防护

### 时间边界

- 所有分析必须声明 `as_of` 日期（默认为当前日期）
- 不得引用 `as_of` 之后发布的数据作为已知事实
- 回测中不得使用未来数据（财报发布日 vs 报告期末日区分）

### 预测标注

- 前瞻性预测必须标注 `[预测]` 并说明预测依据
- 预测区间优于点估计（如 "2026 年营收 50-70 亿" 优于 "60 亿"）
- 情景分析（牛/基/熊）优于单一预测

## 分歧处理

当不同等级的证据之间存在矛盾时：

1. **P0 之间矛盾**: 标注矛盾，不做主观判断，等待更多信息
2. **P0 vs P1**: 以 P0 为准，标注 P1 的不同观点
3. **P1 vs P2/P3**: 以 P1 为准，将低等级观点作为"待验证线索"
4. **所有来源一致**: 反而需要警惕——共识过于一致可能意味着信息已充分定价
