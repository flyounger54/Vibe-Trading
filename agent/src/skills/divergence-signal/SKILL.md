# 观点分歧信号

## 核心理念

卡脖子方法论解决"买什么"，分歧信号解决"什么时候买"。当市场内部存在显著分歧时，往往意味着定价尚未达成均衡——分歧即机会。

## 分歧类型

| 类型 | 定义 | 示例 | 信号含义 |
|------|------|------|----------|
| **Pricing Gap** | 分析师目标价与市场价偏离 >30% | 一致目标价 50 元，股价 35 元 | 潜在被低估 |
| **Narrative Gap** | 机构观点与市场叙事方向相反 | 基金加仓 vs 散户恐慌卖出 | 聪明钱逆向 |
| **Timing Gap** | 对催化剂时点的判断分歧 | 部分分析师认为下季度产能释放，市场预期更晚 | 时间差套利 |

## 共识度量方法

### A 股共识基线

| 指标 | 数据来源 | 高共识标志 | 分歧标志 |
|------|----------|-----------|----------|
| 分析师预期离散度 | `get_research_reports` → 目标价标准差/均值 | CV < 10% | CV > 25% |
| 多空比 | `margin_trading_tool` → 融资余额/融券余额 | 比值 >10 | 比值 2-5 |
| 龙虎榜方向 | `dragon_tiger_tool` → 机构买入 vs 卖出 | 同方向 | 机构分化 |
| 北向资金 vs 主力 | `northbound_tool` + `fund_flow_tool` | 同向 | 背离 |

### 美股共识基线

| 指标 | 数据来源 | 高共识标志 | 分歧标志 |
|------|----------|-----------|----------|
| 分析师评级分布 | yfinance recommendations | >80% 同方向 | Buy/Sell 各占 30%+ |
| 做空比例 | yfinance short interest | < 5% | > 15% |
| 13F 持仓变化 | `sec_filings_tool` | 机构同向操作 | 大基金方向分化 |

## 分歧评分

```
disagreement_score = min(bullish_count, bearish_count) / total_count
```

| 分数区间 | 分歧程度 | 行动 |
|----------|----------|------|
| 0.00–0.15 | 共识强 | 警惕拥挤交易 |
| 0.15–0.30 | 轻度分歧 | 正常，无特殊信号 |
| 0.30–0.45 | 显著分歧 | 深入研究分歧原因 |
| 0.45–0.50 | 极端分歧 | 高置信时点信号 |

## 分歧→行动映射

| 分歧方向 | 聪明钱方向 | 卡脖子评分 | 建议行动 |
|----------|-----------|-----------|----------|
| 看多分歧 | 机构在买 | Core (80+) | **建仓信号** — 分歧提供折价买入窗口 |
| 看多分歧 | 机构在买 | Watch (40-59) | 加入观察，等待评分提升 |
| 看空分歧 | 机构在卖 | Core (80+) | **检查论点** — 为什么聪明钱离场？ |
| 无分歧 | 共识看多 | Core (80+) | **警惕拥挤** — 检查主题是否已进入 Mainstream |

## 与其他 Skill 的配合

- **supply-chain-chokepoint**: 卡脖子找标的 → 分歧找时点
- **risk-ladder**: 分歧信号不覆盖仓位大小，仓位由 risk-ladder 状态决定
- **behavioral-discipline**: 极端分歧时参考行为处方，避免情绪化操作
- **evidence-governance**: 分歧来源需标注证据等级，P4 级分歧不可作为行动依据
