# 节点 8 验收报告：可信 ML 研究链

日期：2026-07-18
分支：`upgrade/node-8-trustworthy-ml-research`

## 已完成的修复

1. 预处理改为持久化 `Preprocessor.fit(train) -> transform(...)`。量化边界、标准化参数、填充值和特征顺序都写入模型元数据与 `model_manifest.json`；监控与推理只恢复这些训练期参数，不能再在 OOS/实时数据上重新拟合。
2. 特征选择移动到每一个 walk-forward 折的训练区间内。每折严格按 `训练 -> 可选校准 -> 真实 OOS` 的时间顺序执行，最终模型保留最后一折的训练/校准结果，不再用全样本回训后把其中一段当作 OOS。
3. 新增标签、选择、预处理、校准和幸存者偏差的独立泄漏审计项。训练数据、校准数据和 OOS 数据的重叠或顺序错误会被明确记录为失败。
4. 请求超额收益标签时，基准行情无法取得会抛出 `BenchmarkUnavailableError`，不再静默降级为绝对收益标签。
5. 特征缓存键现在绑定完整数据指纹、日期范围、PIT 成分指纹、因子源码版本和滚动回看长度；标签缓存键补齐阈值、分位数、标签版本与数据指纹。缓存使用项目已声明的 DuckDB 原生 Parquet，损坏缓存会失效并重建。增长数据只会在验证历史前缀完全一致后，以足够回看长度增量计算。
6. 无 PIT 成分的数据集会被明确标记为 `research_only`，且无法提升为生产模型；集成模型同样要求每个子模型已通过资格门禁、共享同一特征模式和预处理清单。
7. 新增 `ModelManifest`，记录数据与 PIT 指纹、候选/选择特征、预处理参数、每折切分、随机种子、依赖版本、指标及资格状态。
8. 模型比较改为读取回测运行器的规范产物 `artifacts/metrics.csv`，不再读取不存在的顶层 `metrics.json`。
9. 训练任务改为原子持久化的 Job Store；服务重启会把未完成任务标记为 `interrupted`，支持取消请求和来自真实流水线阶段的 SSE 进度事件。
10. 新增取消训练 API 后，已重新生成 OpenAPI schema、前端类型和客户端操作清单。

## 生产资格结论

只有同时满足以下条件的模型才可提升为生产版本：PIT 成分可用、泄漏审计通过、`production_eligible=true`。否则模型仍可用于研究和回测，但不能被调度器提升或作为生产集成模型的成员。

## 已知非阻塞项

专项测试会显示第三方 FastAPI/Starlette 弃用警告，以及合成常量预测触发的 Spearman 常量输入警告；两者均不影响断言结果，且不属于本节点引入的运行失败。
