# 节点 9 验收报告：产业链与高级研究模块产品化

日期：2026-07-18
分支：`upgrade/node-9-industry-research-productization`
基线：`upgrade-node-8-accepted`（`de570ef`）

## 已完成的修复

1. 产业链、研究历史和刷新计划已迁移到统一的 WAL SQLite 状态库；旧 JSON 目录只会在首次启动时导入，后续不再作为权威状态。
2. 产业链写入使用行版本乐观锁。更新请求必须携带 `row_version`，并发陈旧写入返回 `409`；每次研究结果和手工快照都是不可变版本。
3. 所有产业链路由（含模板、列表、详情、比较、历史、导出、调度和任务操作）均强制认证；静态 `/industry-chain/compare` 已在 `/{chain_id}` 前注册，避免被动态路由误吞。
4. Swarm 研究输出改为 `IndustryResearchResult` 结构化 schema：节点、边、分段、标的、证据、冲突、来源、as-of、有效期和置信度全部受校验；自由文本不再能写入研究事实。
5. 缺失、过期或冲突证据会产生 `missing`、`stale`、`conflicting` 生命周期状态。前端不再渲染确定性评分、图表或结论，而是显示证据账本、来源、as-of 和未解决冲突。
6. 新增持久刷新任务队列，支持幂等键、同产业链并发抑制、失败重试、取消、服务重启恢复及每周/每月自动调度；链级分析与 job API 可查询、取消和重试。
7. 新增历史版本比较和可导出研究产物，导出包含 as-of、证据和冲突信息，避免将过期结论脱离上下文传播。
8. 前端新增证据状态徽标、版本比较界面、失败原因、取消和重试操作；自定义产业链表单的标签与输入已正确关联，保证可访问性和稳定的 UI 自动化定位。
9. 修复真实服务中的访问日志可靠性缺陷：脱敏过滤器此前清空了 Uvicorn `AccessFormatter` 依赖的五元参数，导致每个成功请求都产生格式化 traceback。现在仅脱敏消息及字符串参数，同时保留结构化访问日志参数，并加入回归测试。

## 生产资格结论

产业链研究只有在结构化 schema 校验通过、证据仍有效且没有未解决冲突时，才会在界面中作为可支持的研究事实呈现。无效输出会使任务失败并保留错误信息，过期、缺失或冲突数据会明确降级为不确定状态，而不会显示为确定性投资结论。
